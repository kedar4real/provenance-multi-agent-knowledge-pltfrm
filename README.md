# provenance

A secure multi-agent knowledge platform. A supervisor agent decomposes questions and delegates to retrieval, SQL and verification workers, then synthesizes one cited answer. A central controller owns caching, routing, budgets, escalation and abstention, driven by a calibrated confidence score. It is demonstrated on SEC 10-K filings.
